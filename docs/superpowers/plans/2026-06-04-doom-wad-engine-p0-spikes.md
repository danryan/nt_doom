# Doom WAD engine: P0 feasibility-spike Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the host tools and three on-device probes that answer the three
viability questions (WAD-via-WAV byte-exact read, DRAM grant size, renderer-core
`.text` budget) before any engine spec is written.

**Architecture:** Clean-room original code only. A host-side WAV wrapper and a
synthetic-WAD builder (both TDD'd in Catch2), two integer hardware probes under
`plugins/probes/`, and one non-interactive renderer-core spike under `plugins/games/`
built through a new `BUILD_GAME` pipeline that mirrors `BUILD_PER_APPLET` minus the
shim. The renderer spike shares pure headers (`plugins/games/doom/*.h`) with host
tests so the rendering logic is verified on the host before the `.text` measurement on
ARM.

**Tech Stack:** C++ (host: `clang++`/`g++` + Catch2; target: `arm-none-eabi-c++` +
compiler-rt + section-merge), GNU Make, `arm-none-eabi-nm`/`readelf` for size, NT
plug-in ABI (`vendor/distingNT_API` only).

## File structure

Created by this plan:

- `harness/tools/wav_wrap.h` — pure function `wrap_wav_8bit_mono(payload)` returning a
  WAV byte vector. One responsibility: produce a canonical 8-bit mono PCM WAV.
- `harness/tools/wav_wrap.cpp` — CLI wrapping `wrap_wav_8bit_mono` over a file.
- `harness/tests/test_wav_wrap.cpp` — Catch2 tests for the header fields and payload
  passthrough.
- `plugins/games/doom/wad.h` — clean-room WAD container parse (header, directory,
  lump lookup). Shared by host tests, the WAD builder, and the ARM spike.
- `harness/tools/wad_build.h` — `build_test_wad()` returning the bytes of a minimal
  valid IWAD with one square-room map (`E1M1`).
- `harness/tools/wad_build.cpp` — CLI that writes the test WAD as a C header
  (`const uint8_t kDoomTestWad[]`) to stdout.
- `harness/tests/test_wad.cpp` — Catch2 tests: build then parse, assert lump count,
  names, and map-lump sizes.
- `plugins/games/doom/geom.h` — map view: typed pointers and counts over the WAD map
  lumps (VERTEXES, LINEDEFS, SIDEDEFS, SECTORS, SEGS, SSECTORS, NODES). Zero-copy.
- `plugins/games/doom/fb.h` — 4-bit framebuffer pixel write matching
  `shim/src/graphics.cpp` packing, over a caller-supplied `uint8_t[128*64]`.
- `plugins/games/doom/render.h` — `render_view(map, camera, fb)`: BSP-or-degenerate
  traversal, perspective wall-column projection, affine texture-column sampling,
  distance shading to 16 gray levels.
- `harness/tests/test_doom_render.cpp` — Catch2 sanity tests for `render_view`.
- `plugins/games/doom_test_map.h` — generated by `wad_build` (committed; deterministic).
- `plugins/games/doom_core_spike.cpp` — non-interactive ARM spike: builds the map from
  `doom_test_map.h`, renders once per `draw()` into `NT_screen`. The `.text` target.
- `plugins/probes/wad_read_probe.cpp` — Spike A: reads a WAV-wrapped pattern back via
  `NT_readSampleFrames` and `NT_streamOpen`, renders the bytes to screen.
- `plugins/probes/dram_grant_probe.cpp` — Spike B: requests escalating DRAM, writes and
  verifies a sentinel, renders granted size and pass/fail.
- `docs/superpowers/abort-reports/2026-06-04-doom-p0-spike-results.md` — captured
  outcomes and go/no-go.

Modified:

- `Makefile` — add `BUILD_GAME` macro, `GAME_LIST`, host rules for the tools and tests,

```cpp
#pragma once
#include <cstdint>
#include <vector>

inline void put_u32le(std::vector<uint8_t>& v, uint32_t x) {
    v.push_back(x & 0xFF); v.push_back((x >> 8) & 0xFF);
    v.push_back((x >> 16) & 0xFF); v.push_back((x >> 24) & 0xFF);
}
inline void put_u16le(std::vector<uint8_t>& v, uint16_t x) {
    v.push_back(x & 0xFF); v.push_back((x >> 8) & 0xFF);
}
inline void put_str(std::vector<uint8_t>& v, const char* s) {
    for (int i = 0; i < 4; ++i) v.push_back((uint8_t)s[i]);
}

// Canonical 8-bit unsigned mono PCM WAV. Payload bytes are the raw sample data
// and are emitted verbatim after the 44-byte header.
inline std::vector<uint8_t> wrap_wav_8bit_mono(const std::vector<uint8_t>& payload,
                                               uint32_t sampleRate) {
    std::vector<uint8_t> v;
    uint32_t dataLen = (uint32_t)payload.size();
    put_str(v, "RIFF"); put_u32le(v, 36 + dataLen); put_str(v, "WAVE");
    put_str(v, "fmt "); put_u32le(v, 16);
    put_u16le(v, 1);              // PCM
    put_u16le(v, 1);              // mono
    put_u32le(v, sampleRate);
    put_u32le(v, sampleRate);     // byte rate = sampleRate * 1 * 1
    put_u16le(v, 1);              // block align
    put_u16le(v, 8);              // bits per sample
    put_str(v, "data"); put_u32le(v, dataLen);
    v.insert(v.end(), payload.begin(), payload.end());
    return v;
}
```

`harness/tools/wav_wrap.cpp`:

```cpp
#include "wav_wrap.h"
#include <cstdio>
#include <vector>

int main(int argc, char** argv) {
    if (argc != 3) { fprintf(stderr, "usage: wav_wrap <in> <out.wav>\n"); return 2; }
    FILE* in = fopen(argv[1], "rb");
    if (!in) { fprintf(stderr, "cannot open %s\n", argv[1]); return 1; }
    std::vector<uint8_t> payload;
    uint8_t buf[65536]; size_t n;
    while ((n = fread(buf, 1, sizeof(buf), in)) > 0) payload.insert(payload.end(), buf, buf + n);
    fclose(in);
    std::vector<uint8_t> wav = wrap_wav_8bit_mono(payload, 48000);
    FILE* out = fopen(argv[2], "wb");
    if (!out) { fprintf(stderr, "cannot write %s\n", argv[2]); return 1; }
    fwrite(wav.data(), 1, wav.size(), out);
    fclose(out);
    return 0;
}
```

- [ ] **Step 3: Write `plugins/games/doom/wad.h`**

```cpp
#pragma once
#include <cstdint>
#include <cstring>

namespace doom {

struct WadHeader { char id[4]; int32_t numLumps; int32_t dirOffset; };
struct WadDirEntry { int32_t filePos; int32_t size; char name[8]; };

struct Wad {
    const uint8_t* base = nullptr;
    uint32_t size = 0;
    const WadDirEntry* dir = nullptr;
    int32_t numLumps = 0;
};

inline bool wad_open(const uint8_t* data, uint32_t size, Wad& w) {
    if (size < sizeof(WadHeader)) return false;
    const WadHeader* h = reinterpret_cast<const WadHeader*>(data);
    if (memcmp(h->id, "IWAD", 4) != 0 && memcmp(h->id, "PWAD", 4) != 0) return false;
    if (h->numLumps < 0 || h->dirOffset < 0) return false;
    uint64_t dirEnd = (uint64_t)h->dirOffset + (uint64_t)h->numLumps * sizeof(WadDirEntry);
    if (dirEnd > size) return false;
    w.base = data; w.size = size;
    w.dir = reinterpret_cast<const WadDirEntry*>(data + h->dirOffset);
    w.numLumps = h->numLumps;
    return true;
}

inline int32_t wad_find_lump(const Wad& w, const char* name, int32_t start = 0) {
    char pad[8]; memset(pad, 0, 8);
    for (int i = 0; i < 8 && name[i]; ++i) pad[i] = name[i];
    for (int32_t i = start; i < w.numLumps; ++i)
        if (memcmp(w.dir[i].name, pad, 8) == 0) return i;
    return -1;
}

inline const uint8_t* wad_lump_ptr(const Wad& w, int32_t idx) {
    return w.base + w.dir[idx].filePos;
}
inline uint32_t wad_lump_size(const Wad& w, int32_t idx) {
    return (uint32_t)w.dir[idx].size;
}

} // namespace doom
```

- [ ] **Step 4: Write `harness/tools/wad_build.h`**

A minimal IWAD with one convex square room. NODES is intentionally empty (size 0);
the renderer treats `numNodes == 0` as "subsector 0 is the whole view".

```cpp
#pragma once
#include <cstdint>
#include <cstring>
#include <vector>

namespace wadbuild {

inline void w16(std::vector<uint8_t>& v, int16_t x) {
    v.push_back((uint8_t)(x & 0xFF)); v.push_back((uint8_t)((x >> 8) & 0xFF));
}
inline void name8(std::vector<uint8_t>& v, const char* s) {
    char b[8]; memset(b, 0, 8); for (int i = 0; i < 8 && s[i]; ++i) b[i] = s[i];
    for (int i = 0; i < 8; ++i) v.push_back((uint8_t)b[i]);
}

struct Lump { char name[8]; std::vector<uint8_t> data; };

} // namespace wadbuild

// Builds a valid IWAD: E1M1 marker + THINGS, VERTEXES, LINEDEFS, SIDEDEFS,
// SEGS, SSECTORS, NODES (empty), SECTORS. One 256x256 square sector.
inline std::vector<uint8_t> build_test_wad() {
    using namespace wadbuild;
    std::vector<Lump> lumps;
    auto add = [&](const char* nm, std::vector<uint8_t> d) {
        Lump L; memset(L.name, 0, 8);
        for (int i = 0; i < 8 && nm[i]; ++i) L.name[i] = nm[i];
        L.data = std::move(d); lumps.push_back(std::move(L));
    };

    add("E1M1", {});

    // THINGS: one player-1 start at (128,128) facing east. Record: x,y,angle,type,flags.
    { std::vector<uint8_t> d; w16(d,128); w16(d,128); w16(d,0); w16(d,1); w16(d,7); add("THINGS", d); }

    // VERTEXES: square corners.
    { std::vector<uint8_t> d;
      int16_t xs[4]={0,256,256,0}, ys[4]={0,0,256,256};
      for (int i=0;i<4;++i){ w16(d,xs[i]); w16(d,ys[i]); } add("VERTEXES", d); }

    // LINEDEFS: v1,v2,flags,special,tag,front,back(0xFFFF). 4 one-sided lines.
    { std::vector<uint8_t> d;
      int p[4][2]={{0,1},{1,2},{2,3},{3,0}};
      for (int i=0;i<4;++i){ w16(d,p[i][0]); w16(d,p[i][1]); w16(d,1); w16(d,0); w16(d,0); w16(d,i); w16(d,(int16_t)0xFFFF); }
      add("LINEDEFS", d); }

    // SIDEDEFS: xoff,yoff,upper,lower,middle,sector. middle="WALL".
    { std::vector<uint8_t> d;
      for (int i=0;i<4;++i){ w16(d,0); w16(d,0); name8(d,"-"); name8(d,"-"); name8(d,"WALL"); w16(d,0); }
      add("SIDEDEFS", d); }

    // SEGS: v1,v2,angle(BAM),linedef,side,offset. One seg per line.
    { std::vector<uint8_t> d;
      int p[4][2]={{0,1},{1,2},{2,3},{3,0}};
      int16_t ang[4]={0,(int16_t)16384,(int16_t)-32768,(int16_t)-16384};
      for (int i=0;i<4;++i){ w16(d,p[i][0]); w16(d,p[i][1]); w16(d,ang[i]); w16(d,i); w16(d,0); w16(d,0); }
      add("SEGS", d); }

    // SSECTORS: numsegs, firstseg.
    { std::vector<uint8_t> d; w16(d,4); w16(d,0); add("SSECTORS", d); }

    // NODES: empty (degenerate single-subsector map).
    add("NODES", {});

    // SECTORS: floorh,ceilh,floortex,ceiltex,light,special,tag.
    { std::vector<uint8_t> d; w16(d,0); w16(d,128); name8(d,"FLAT"); name8(d,"FLAT"); w16(d,200); w16(d,0); w16(d,0); add("SECTORS", d); }

    // Assemble: 12-byte header, lump data, then directory.
    std::vector<uint8_t> out;
    auto o32 = [&](std::vector<uint8_t>& v, int32_t x){
        v.push_back(x & 0xFF); v.push_back((x>>8)&0xFF); v.push_back((x>>16)&0xFF); v.push_back((x>>24)&0xFF); };
    out.push_back('I'); out.push_back('W'); out.push_back('A'); out.push_back('D');
    o32(out, (int32_t)lumps.size());
    int32_t dirOffsetPos = (int32_t)out.size();
    o32(out, 0); // patched later

    std::vector<std::pair<int32_t,int32_t>> dir; // (filePos, size)
    for (auto& L : lumps) {
        int32_t pos = (int32_t)out.size();
        out.insert(out.end(), L.data.begin(), L.data.end());
        dir.push_back({pos, (int32_t)L.data.size()});
    }
    int32_t dirStart = (int32_t)out.size();
    for (size_t i = 0; i < lumps.size(); ++i) {
        o32(out, dir[i].first); o32(out, dir[i].second);
        out.insert(out.end(), lumps[i].name, lumps[i].name + 8);
    }
    out[dirOffsetPos+0] = dirStart & 0xFF; out[dirOffsetPos+1] = (dirStart>>8)&0xFF;
    out[dirOffsetPos+2] = (dirStart>>16)&0xFF; out[dirOffsetPos+3] = (dirStart>>24)&0xFF;
    return out;
}
```

```cpp
#pragma once
#include <cstdint>
#include "wad.h"

namespace doom {

#pragma pack(push, 1)
struct VertexRaw  { int16_t x, y; };
struct SegRaw     { int16_t v1, v2, angle, linedef, side, offset; };
struct SubsecRaw  { int16_t numSegs, firstSeg; };
struct SectorRaw  { int16_t floorH, ceilH; char floorTex[8], ceilTex[8]; int16_t light, special, tag; };
struct LinedefRaw { int16_t v1, v2, flags, special, tag, front, back; };
struct SidedefRaw { int16_t xoff, yoff; char upper[8], lower[8], middle[8]; int16_t sector; };
#pragma pack(pop)

struct Map {
    const VertexRaw*  verts   = nullptr; int32_t numVerts   = 0;
    const SegRaw*     segs    = nullptr; int32_t numSegs    = 0;
    const SubsecRaw*  ssecs   = nullptr; int32_t numSsecs   = 0;
    const SectorRaw*  sectors = nullptr; int32_t numSectors = 0;
    const LinedefRaw* lines   = nullptr; int32_t numLines   = 0;
    const SidedefRaw* sides   = nullptr; int32_t numSides   = 0;
    int32_t numNodes = 0;
};

inline bool map_load(const Wad& w, const char* mapName, Map& m) {
    int32_t base = wad_find_lump(w, mapName);
    if (base < 0) return false;
    auto lump = [&](const char* nm, const uint8_t** p, int32_t recSize, int32_t* count) -> bool {
        int32_t i = wad_find_lump(w, nm, base);
        if (i < 0) return false;
        *p = wad_lump_ptr(w, i);
        *count = recSize ? (int32_t)(wad_lump_size(w, i) / recSize) : 0;
        return true;
    };
    const uint8_t* p;
    if (lump("VERTEXES", &p, sizeof(VertexRaw),  &m.numVerts))   m.verts   = (const VertexRaw*)p;   else return false;
    if (lump("SEGS",     &p, sizeof(SegRaw),     &m.numSegs))    m.segs    = (const SegRaw*)p;      else return false;
    if (lump("SSECTORS", &p, sizeof(SubsecRaw),  &m.numSsecs))   m.ssecs   = (const SubsecRaw*)p;   else return false;
    if (lump("SECTORS",  &p, sizeof(SectorRaw),  &m.numSectors)) m.sectors = (const SectorRaw*)p;   else return false;
    if (lump("LINEDEFS", &p, sizeof(LinedefRaw), &m.numLines))   m.lines   = (const LinedefRaw*)p;  else return false;
    if (lump("SIDEDEFS", &p, sizeof(SidedefRaw), &m.numSides))   m.sides   = (const SidedefRaw*)p;  else return false;
    int32_t ni = wad_find_lump(w, "NODES", base);
    m.numNodes = (ni < 0) ? 0 : (int32_t)(wad_lump_size(w, ni) / 28);
    return true;
}
```

- [ ] **Step 5: Write `plugins/games/doom/render.h`**

Spike-grade renderer: enough real work (projection, per-column wall height, affine

```cpp
#pragma once
#include <cstdint>
#include "geom.h"
#include "fb.h"

namespace doom {

struct Camera { float x, y, angle; };

static const int kScreenW = 256;
static const int kScreenH = 64;

// A 16x16 procedural-ish wall texture in rodata (gray 0..15). Exercises the
// texture-sample code path for the .text measurement.
static const uint8_t kWallTex[16 * 16] = {
#define R0 12,12,11,11,12,12,11,11,12,12,11,11,12,12,11,11
    R0,R0,R0,R0,R0,R0,R0,R0,R0,R0,R0,R0,R0,R0,R0,R0
#undef R0
};

inline uint8_t shade(uint8_t base, float dist) {
    float atten = 64.0f / (dist + 1.0f);   // closer = brighter
    if (atten > 1.0f) atten = 1.0f;
    int g = (int)(base * atten);
    if (g < 0) g = 0; if (g > 15) g = 15;
    return (uint8_t)g;
}

// Renders the walls of subsector 0 into fb (128*64). Float math, FPU-friendly.
inline void render_view(const Map& m, const Camera& cam, uint8_t* fb) {
    fb_clear(fb);
    if (m.numSsecs == 0) return;
    const SubsecRaw& ss = m.ssecs[0];
    float ca = /* cos */ 1.0f, sa = /* sin */ 0.0f;
    // Small inline cos/sin via Taylor-free approximation table would live here in
    // production; for the spike use the standard library only on host. On ARM this
    // header is compiled with a rodata sine LUT (see doom_core_spike.cpp).
    cos_sin(cam.angle, ca, sa);

    const float fovScale = (float)kScreenW / 2.0f;   // ~90 deg horizontal
    for (int s = 0; s < ss.numSegs; ++s) {
        const SegRaw& seg = m.segs[ss.firstSeg + s];
        const VertexRaw& a = m.verts[seg.v1];
        const VertexRaw& b = m.verts[seg.v2];

        // World to camera space.
        float ax = a.x - cam.x, ay = a.y - cam.y;
        float bx = b.x - cam.x, by = b.y - cam.y;
        float a1 =  ax * ca + ay * sa, a2 = -ax * sa + ay * ca;
        float b1 =  bx * ca + by * sa, b2 = -bx * sa + by * ca;
        // a1/b1 are depth (forward), a2/b2 are lateral.

        if (a1 <= 1.0f && b1 <= 1.0f) continue;   // behind camera
        if (a1 < 1.0f) a1 = 1.0f;
        if (b1 < 1.0f) b1 = 1.0f;

        int sxA = (int)(kScreenW / 2 + (a2 / a1) * fovScale);
        int sxB = (int)(kScreenW / 2 + (b2 / b1) * fovScale);
        if (sxA > sxB) { int t = sxA; sxA = sxB; sxB = t; float td=a1; a1=b1; b1=td; }
        if (sxB <= sxA) continue;

        for (int x = sxA; x <= sxB; ++x) {
            if (x < 0 || x >= kScreenW) continue;
            float t = (sxB == sxA) ? 0.0f : (float)(x - sxA) / (float)(sxB - sxA);
            float depth = a1 + (b1 - a1) * t;
            float wallH = (kScreenH * 32.0f) / depth;
            int top = (int)(kScreenH / 2 - wallH / 2);
            int bot = (int)(kScreenH / 2 + wallH / 2);
            if (top < 0) top = 0; if (bot >= kScreenH) bot = kScreenH - 1;
            int u = ((int)(t * 16.0f)) & 15;
            for (int y = top; y <= bot; ++y) {
                int vtex = ((y - top) * 16) / (bot - top + 1);
                if (vtex < 0) vtex = 0; if (vtex > 15) vtex = 15;
                uint8_t texel = kWallTex[vtex * 16 + u];
                fb_put(fb, x, y, shade(texel, depth));
            }
        }
    }
}

} // namespace doom
```

## Abort conditions

- Spike A read is not byte-exact (firmware transforms sample data) and no stream
  variant returns raw bytes: HALT. The "load real WADs" requirement has no hardware
  path. Surface to the user with the screen evidence.
- Spike C renderer-core `.text` exceeds ~70KB: do NOT proceed to the full engine as
  designed. Surface a scope decision (drop texture mapping, simplify the renderer)
  before P1.
- Any probe hard-faults on add (not just fails to register): power-cycle, remove the
  bad `.o` via USB disk mode, and record the fault registers per the repo's
  diagnostic discipline before retrying.
